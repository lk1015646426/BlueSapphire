# BlueSapphire AI 智能助手架构

## 定位

AI 智能助手是应用的自然语言编排层。清理、媒体、日志和扩展服务仍然负责真实执行与安全判断；模型不能替代路径边界、风险规则、确认弹窗和审计记录。

## 统一任务链路

所有长时间或有副作用的 AI 操作使用 `AITaskCenterService`：

1. 通过任务类型和幂等键创建任务。
2. 持续记录进度、摘要和时间线。
3. 页面切换不取消任务。
4. 用户可以在全局“任务中心”取消任务。
5. 应用重启后，未结束任务标记为“已中断”。
6. 删除、移动或写入任务不会在重启后自动续跑，必须重新确认。

## 共享上下文

`AISharedContextService` 保存当前会话内的：

- 最近清理扫描结果；
- 当前媒体管家目录；
- 最近媒体分析结果；
- 最近媒体整理预览。

清理扫描结果最多在 30 分钟内用于删除确认，防止使用过期结果执行操作。

## 操作协议

涉及多个模块或副作用时采用：

`理解需求 → 只读计划 → 扫描/预览 → 分项确认 → 执行 → 审计与恢复`

扫描授权、缓存清理授权、媒体删除授权和媒体移动授权相互独立，不能继承。

## 数据保护

- 对话历史和长期记忆使用当前 Windows 账户加密。
- 长期记忆支持范围、有效期、暂停、编辑和删除。
- 发送给远程模型前，对用户名、邮箱、Bearer Token、API Key 和 URL 密钥参数进行脱敏。
- 本地任务中心只持久化任务摘要，不保存清理目标文件清单。
- 模型不可用时，本地降级模式仍支持导航、快速扫描、任务摘要和最近扫描摘要。

## 媒体安全边界

- 媒体分析和整理计划默认只读。
- 完全重复图片使用 SHA-256 校验。
- 相似图片不会自动删除。
- 重复图片仅移入系统回收站。
- 按年月归档不会覆盖同名文件，冲突项直接跳过。
- BlueSapphire 标签会随归档移动。

## 规则草稿

AI 生成的清理规则始终满足：

- 禁止磁盘根目录和 Windows 核心根目录；
- 初始风险为高风险；
- 初始执行方式为 `None`；
- 初始状态仅供查看；
- 只保存到草稿目录，不自动导入或启用。

## 验证

AI 场景测试覆盖任务幂等、取消、重启中断、进度单调、共享上下文克隆、扫描结果过期、隐私脱敏、确认授权和结构化记忆迁移。

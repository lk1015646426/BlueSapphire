# 清理助手真实流程验收矩阵

更新时间：2026-07-22

本矩阵定义“清理助手已经可用”的真实口径。功能存在、代码可编译或单个服务测试通过，都不能单独算完成。

## 不变量

1. 任一时刻只能有一个会读取或修改磁盘状态的主操作：扫描、清理、失败重试、恢复、清空隔离区。
2. 扫描范围必须来自用户当前选中的磁盘；结果、任务去重指纹和深度分析范围使用同一份范围快照。
3. 新扫描期间不展示旧结果；取消或失败时只恢复上一次完整报告，绝不混合两次扫描结果。
4. AI 只能解释证据，不能改变风险、可选性、执行方式、边界或用户确认。
5. 隔离只算可恢复暂存，永久删除或系统动作才算实际释放；界面、历史、审计和 AI 使用同一口径。
6. 所有可写操作都有取消、失败结果和可核对记录；窗口关闭不得等待 UI 线程回调而卡死。

## 发布门禁

- 修改扫描范围、风险或执行边界：必须补服务级文件系统测试。
- 修改 ViewModel 状态：必须补从用户入口触发的流程测试，不能只测私有方法。
- 修改 XAML：必须完成 XAML 编译并启动真实 WinUI 窗口。
- 修改窗口生命周期：必须验证运行中关闭和再次启动，不能使用 UI 线程同步等待。
- 矩阵存在“待最终验证”或“失败”时，不得宣称清理助手全部完成。

### 最终代码审查修复

代码审查发现 CleanerOperationCoordinator.StateChanged 订阅者异常会从 TryAcquire 逸出，使已获得的租约无法交还调用方并可能长期保持忙碌。新增 RED 测试 ThrowingStateChangedSubscriber_DoesNotLeakOperationLease 后，将状态通知改为逐订阅者隔离；聚焦测试 3/3、最近工作流测试 24/24、隔离工作树测试和构建均通过。

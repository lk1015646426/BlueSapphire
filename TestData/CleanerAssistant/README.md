# Cleaner Assistant Test Data

This folder is used for repeatable local smoke tests of the cleaner module.

- `QuickCache`: low-risk cache-like sample.
- `ReviewCache`: review-tier sample data.
- `ViewOnlyHints`: large-file sample for analysis-only validation.
- `ExcludedSample`: path-boundary exclusion sample.

These files are disposable and safe to recreate.
